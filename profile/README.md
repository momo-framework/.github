# MOMO FRAMEWORK

> **Build with PHP, Run like Go.**
> Скорость разработки PHP × Производительность C-расширений.

Momo — это современный PHP-фреймворк, спроектированный по принципу **Event-Driven Modular Monolith**. Он позволяет создавать сложные enterprise-системы (например, E-commerce), которые легко масштабируются из монолита в микросервисы без переписывания кодовой базы.

## Стек

PHP 8.5 · Swoole · PostgreSQL 16 · KeyDB · Symfony DI · FastRoute · Cycle ORM · Docker

## Репозитории

- [framework](https://github.com/momo-framework/framework) — приложение-скелет, с которого начинается проект
